\paragraph{A common cost unit.}
In a distance-count model, let $C_{\rm acquire}$ include the nonshared profile, truth, selection, and certification work, and let $\bar c$ denote serving work per execution. For a fixed expected workload,
\begin{align}
 C_\pi(N)&=C_{\mathrm{acquire},\pi}+N\bar c_\pi,\label{eq:cost}\\
 N_{\mathrm{BE}}&=\frac{C_{\mathrm{acquire},\pi}-C_{\mathrm{acquire},\mathrm{ref}}}
 {\bar c_{\mathrm{ref}}-\bar c_\pi},\label{eq:breakeven}
\end{align}
when the denominator is positive and the acquisition difference is positive. Nonpositive acquisition difference means immediate modeled amortization if serving is cheaper; nonpositive serving savings require a separate case rather than a positive break-even claim. Shared costs cancel only when the competing strategies genuinely incur the same cost.

\paragraph{Conditional model outputs.}
The current dataset summaries report break-even at \WZeroSiftBreakEven\ query executions for SIFT and \WZeroArxivBreakEven\ for Arxiv. Zero SIFT targets and \WZeroArxivNonamortizing\ Arxiv target have no positive modeled serving savings. These values condition on the source-profile cost treatment and reuse assumptions in the frozen model. Target truth is charged, but old-build truth is not explicitly included as a separate acquisition term. A valid lifecycle interpretation therefore requires its shared or sunk status to be specified symmetrically for the reference strategy.

\paragraph{Operational conclusion to test against the final evidence.}
TCP recovery is useful when the needed query profiles are available, target recalibration yields an acceptable operating point, and the serving horizon amortizes acquisition work. For a new-query workload, the missing profile-acquisition path changes both deployment and economics. The final text will give these regimes rather than claim that one recovery strategy dominates at every horizon.
