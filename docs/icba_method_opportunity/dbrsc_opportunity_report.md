# DBRSC opportunity report

CFSR-Lite changed 39% of independent calibration traces, so the intervention was not inert, but both budget endpoints worsened and Recall fell by 0.002. The failure therefore identifies a structure-to-budget surrogate mismatch, not a validated direct budget objective. No bounded second-generation optimizer with hard Recall/path constraints is present in frozen evidence. DBRSC remains long-term high-risk unless a finite direct-response algorithm and non-Oracle counterfactual are specified before implementation.
