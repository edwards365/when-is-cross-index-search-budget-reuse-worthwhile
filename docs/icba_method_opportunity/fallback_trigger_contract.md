# Fallback trigger contract

Fallback route: CRSF. It is activated only if CIBS fails because build amortization has no finite break-even or candidate construction/storage is infeasible, while a preregistered target-specific stopping signal independently shows >=5% gain on both datasets with safe p95 and complete continuation/fallback costs. It is not activated for CIBS statistical-power failure, because CRSF depends on a different sequential-signal assumption but still requires independent certification.
