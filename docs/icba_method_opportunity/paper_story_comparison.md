# Paper story comparison

- **CIBS:** build heterogeneity -> source-only nonportability -> shared target evidence -> certified build-budget selection. Natural, concrete and database-facing; novelty must be narrowly Graph-ANNS-specific.
- **CRSF:** expensive fallback -> reusable prefix -> target-certified stopping -> continue-not-restart. Clear systems story, but ANNiE/QBAT/DARTH crowd the space and realistic two-dataset evidence fails.
- **RPA:** missing unified recovery action -> certificate/cost decomposition -> reuse/recalibrate/retrain/fallback. Understandable but currently generic and lacks real actions.
- **DBRSC:** structural proxy failure -> direct budget-response objective -> constrained construction. Potentially strong database story but no bounded algorithm or positive frozen mechanism.

CIBS is the most reviewable SIGMOD/PVLDB/ICDE story. CRSF has stronger ML overlap but greater direct-prior and evidence risk.
