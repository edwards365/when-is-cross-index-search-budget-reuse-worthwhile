# Executive summary

The unified audit selects CIBS as Primary and CRSF as conditional Fallback. CIBS is the only route with a real finite action object, two-dataset non-Oracle opportunity evidence and a tractable two-week pilot. Under Bonferroni family-wise control, viable configurations retained 9.73%-24.00% budget-proxy improvement with unsafe replicate frequency at or below 0.2%; smaller sentinel sets lost all power. This is not a deployed performance result because real NDC/p95, LOBO and common-unit break-even remain unmeasured. CIBS is therefore promoted to method derivation and a feasibility pilot, while full algorithm implementation is not authorized. CRSF is retained only if CIBS fails on build amortization or storage and a new preregistered target signal passes two-dataset safety and tail Gates. RPA is baseline-only; DBRSC is retired under the frozen evidence.
