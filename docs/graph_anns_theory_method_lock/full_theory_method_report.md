## 2. Main theorem system

### Main Theorem I

For two environment-conditioned transcript laws \(P_0^T,P_1^T\), disjoint nontrivially acceptable action regions \(D_0,D_1\), and loss separation \(\Delta\), every transcript-based randomized rule satisfies

\[
\max_i\mathbb E_i\ell_i\ge \frac{\Delta}{2}\{1-\operatorname{TV}(P_0^T,P_1^T)\}.
\]

Adaptive KL consequences follow by classical Bretagnolle–Huber, Pinsker, data processing, and chain rules. Those inequalities and the Le Cam reduction are classical. The domain-specific contribution is the definition of build environments and conflicting useful Graph-ANNS action regions, plus the mapping from environment decision error to unsafe under-budgeting, conservative computation, fallback, and abstention.

### Main Theorem II

For a named target and a frozen finite action family, endpoint feasibility, action-relevant identifiability, positive risk margin, independent target evidence, and a valid same-event fallback or abstention support a finite-family screen/select/certify procedure. With valid simultaneous selection bounds and an independent one-sided final certificate, the procedure deploys only a risk-\(\delta\) action with probability at least \(1-\alpha\), or invokes the valid fallback/abstention. On the uniform estimation event it attains a \(2\varepsilon_C\) cost bound relative to a margin-separated best safe action.

This is **not** an iff theorem. Endpoint, indistinguishability, no-margin, adaptive reuse of certification evidence, and invalid-fallback constructions establish necessary obstructions. They do not prove that all possible recovery procedures must have exactly the displayed architecture.

### Corollaries

Classical finite-family concentration gives the sufficient order

\[
m=O\!\left(\frac{\log(M/\alpha)}{\gamma^2}\right),
\]

while zero-failure Clopper–Pearson uses

\[
m_{\min}=\left\lceil\frac{\log\alpha_\ell}{\log(1-\delta)}\right\rceil.
\]

These are not a universal exact sample-complexity characterization. Query count, build count, action count, sentinel resolution, and service workload control different uncertainties.

Economic feasibility uses

\[
D=G_{\rm online}-R_{\rm selection}-\Pr(R)\Delta C_f-C_{\rm control}.
\]

When \(D\le0\), there is no finite break-even workload. When \(D>0\),

\[
N^*=\frac{C_{\rm build}+C_{\rm operator}+C_{\rm truth}+C_{\rm cert}}{D}.
\]

Tail costs remain separate estimands.

## 3. ICBA method lock

ICBA is classified as a **certified diagnostic/auditing method**, not a high-performance search algorithm. It validates role separation and implementation semantics; represents unresolved endpoints categorically; estimates build-conditioned response and directed transport; performs fixed-target certification with valid multiplicity control; checks independent fallback evidence; audits mean/tail/economic value; and emits a scope-qualified reuse, recalibrate, retrain, fallback, abstain, or route-rejection decision.

Its guarantee is narrow and useful: under its declared inputs and independence assumptions, it does not label an uncertified fixed-target action safe, and it abstains when neither an action nor fallback has a valid certificate. It does not guarantee an efficient candidate, a deployment gain, superiority to ANNiE/QBAT-style profiling, or safety after an unseen rebuild.

## 4. Falsification ladder

Four method families enter the main paper as one table and at most one paragraph each.

1. **Reuse and target recalibration** tests whether target evidence and history recover safe value. Fixed-target safety can be recovered, but history did not add stable value and strict role separation exposed margin/query-reuse confounding.
2. **Build selection and stable construction** tests candidate attainability and structure-to-response sufficiency. CIBS found no jointly CI-supported action across both datasets; CFSR and O4/O6 failed to create a native-budget Pareto improvement.
3. **Multi-lane and portal rescue** tests conditional failure complementarity, observability, and shared cost. Portal rescue replicated, but absolute safety, truth-free triggering, and economic compression failed.
4. **Certified auditor and fallback** tests whether safety control itself yields a valuable decision. Unsafe acceptance can be driven to zero, yet decisions collapse to maximum budget, fallback, or abstention and retain substantial regret.

The main text uses the cross-family transport evidence, one fixed-target recalibration example, the CIBS attainability failure, portal complementarity/trigger failure, and the auditor safety-versus-value result. Detailed variants, gates, and internal names remain in the appendix/artifact.
