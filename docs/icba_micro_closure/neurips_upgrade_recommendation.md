# NeurIPS Upgrade Recommendation

Recommendation: continue only the theory track, with the scope "safe computational-policy portability under finite or hierarchically sampled environment replacement." The current closed-world ECSE witness is mathematically constructive but empirically nondeployable and fails leave-one-build-out safety.

Before any NeurIPS-scale experiment, require: (1) an open-world confidence/dominance set with an explicit new-environment sampling model; (2) a deployable source response independent of per-query source truth; (3) a safe endpoint on the claimed instance class; (4) a cost model including sentinel truth and controller latency; and (5) a preregistered build-level confirmation design. Until then, do not rent a larger CPU server, build new graph matrices or access sealed validation/formal-test data.

The paper-level contribution can presently be a restricted overlap--separation lower bound, a finite closed-world ECSE upper bound, and a falsifying Graph-ANNS boundary showing that exact finite-library identification does not imply unseen-build portability. It cannot claim a deployable adaptive ANN algorithm.
