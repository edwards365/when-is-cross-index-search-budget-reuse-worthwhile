\section{Assumptions and counterexamples}
The lower bound requires aligned deterministic budget responses on a common
visible state space. Unaligned marginal budget histograms do not identify the
localized common mass. Right-censored maximum-grid observations are not safe
budget labels. Nonmonotone quality curves require stable tail crossing rather
than first crossing.

ECSE execution monotonicity requires nested confidence sets and frozen response
functions; nonnested sets can exchange a low response for a high response and
increase the envelope. Probe-adjusted total cost need not decrease because
information acquisition is charged. Finally, zero budget separation forces
zero migration tax but not zero total overhead: an empty confidence set can
trigger fail-closed execution, producing certification/fallback cost even when
all environment response functions agree.
