## Current artifact versus historical research

The current public reproduction entry is `artifact/`. Earlier research code and documentation remain at their original paths so that historical commits and links stay usable. They are not a second, interchangeable runbook for the current release.

Historical context includes the [previous project overview](history/README_before_icde_artifact.md), [research question](research_question.md), [methodology](methodology.md), [reproducibility notes](reproducibility.md), and [hardware notes](hardware.md). Read these in the context of their originating experiments. Current scope and supported commands are documented in the artifact runbook.
