# GSC theory–method crosswalk

The theory-Delta patch leaves the status
`GSC_THEORY_VALID_CONDITIONAL_EMPIRICAL_BRIDGE_REQUIRED`.  The smoke therefore
tests only the preregistered empirical bridge: O4 response-weighted pruning and
O6 response-aware insertion.  O1/O3 remain baselines or mechanism diagnostics;
they cannot independently support a GSC method claim.  Safety is defined with
the endpoint-aware absolute failure event and the fixed recall tolerance; raw
`ef`, expansion, NDC, p95, and CVaR are kept distinct.  The held-out build
evidence level is `HELDOUT_BUILD_ROBUSTNESS_EVIDENCE`, not an open-world
certificate.
