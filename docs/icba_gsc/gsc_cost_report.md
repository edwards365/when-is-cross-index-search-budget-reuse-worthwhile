# GSC cost report (smoke)

Five 10K SIFT indexes were built with one thread and the frozen hnswlib
configuration; build seconds and index hashes are recorded in
`results/icba_gsc/operator_smoke/operator_trials.csv`.  Certification,
selection, fallback, and final-evaluation costs were intentionally not incurred.
Consequently full online/offline decomposition and finite break-even are
`TOTAL_BREAK_EVEN_NOT_ESTIMABLE`; no cost claim is made.
