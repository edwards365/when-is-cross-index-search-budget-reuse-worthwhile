# Pilot interface decision

## Selected interface

`Interface C — EMPIRICALLY_CALIBRATED_EF_PILOT`

The abstract theorem controls a deterministic expansion-prefix action. The native hnswlib action is independent fixed-`ef` execution with queue capacity and stopping logic based on `max(ef,k)`. No implementation lemma proved a deterministic map from `B_G^{exp}` or an intruder count to `B_G^{ef}`.

## Authorization

A small, design/calibration-only Stable-by-Construction pilot is authorized after the trace extension and role-disjointness checks pass. It may test whether pre-registered certificate features predict or reduce `B_G^{ef}`, expansion, NDC, and p95 work. It may not claim that T-SC5 guarantees native-`ef` safety, and it may not access certification or evaluation truth.

## Required gates before any effect run

- pin index bytes, code commit, metric, compiler/toolchain, threads, and tie policy;
- emit all 24 trace fields or mark a run invalid;
- enforce disjoint design/calibration/certification/evaluation IDs;
- pre-register `ef` grid and endpoint/right-censoring rules;
- verify native/tracer top-k equivalence on deterministic micro-cases;
- reject/rollback repair if protected-edge or connectivity invariants fail;
- report `ef`, expansion, NDC, and wall time separately, including p95.

## Prohibited interpretation

The pilot tests an empirical bridge; it does not validate an abstract theorem by observation. A positive correlation is not equivalence, a lower average NDC is not p95 control, and right-censored endpoints are not maximum-`ef` successes.
