# Preregistration audit

The four O4 configurations were registered before the earlier validation smoke and are replayed exactly: conservative, balanced, robust, and tie-only. No parameter, threshold, ef grid, split, baseline, or algorithm definition was changed. Because no dedicated O4 validation index existed, the allowed delayed preregistered arm uses the original 500 validation queries; it is not independent confirmatory evidence. Certification, final evaluation, and future-confirm roles were not accessed. See `preregistration_audit.csv` and `query_role_audit.csv`.
