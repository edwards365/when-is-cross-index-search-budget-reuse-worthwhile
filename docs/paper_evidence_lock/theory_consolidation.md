# Theory consolidation

The paper uses three restricted results. Main Result I is a classical finite-environment testing/TV application to observable transcript collisions. Main Result II is a domain-specific restricted proposition: endpoint feasibility, positive source margin, identifiability, sufficient target evidence, and a valid fallback are jointly necessary for safe recovery under the stated finite-action model. Main Result III combines the deployment value identity with classical tail-cost accounting; it is not presented as an open-world theorem.

All theory-to-experiment links are conditional on hnswlib and on the frozen budget semantics. Faiss HNSW and Vamana remain scope boundaries, not positive evidence.
