# Limitations

1. The local clone could not authenticate to fetch private source commits; source contents were verified through the connected GitHub API and the work was staged on a different local parent.
2. DiskANN's default branch is now Rust DiskANN3. It is related to, but not semantically identical with, the legacy C++ implementation used by much of the literature.
3. A configured random seed does not prove deterministic parallel build replay. Preflight is mandatory.
4. The pilot covers two datasets, one exact implementation commit, one provider mode, one fixed beam width and six raw list sizes.
5. Fixed-target query inference does not supply outer-build or future-version coverage.
6. The graph-summary counterexample shows that the registered structural features cannot certify transport stability.
7. Right-censoring is grid-relative and cannot establish that no safe action exists outside the grid.
8. Nonmonotone raw response prevents event nesting and invalidates the originally proposed event list; `OVER_BUDGET_UNSAFE` must be retained.
9. In-memory and SSD costs are distinct. Stage-I results cannot be advertised as SSD deployment performance.
10. The prior-art conclusion is scoped to the reviewed Level A/B sources and is not a priority claim.
11. No experimental outcome, evaluation truth or future-replication evidence was examined in this lock.
