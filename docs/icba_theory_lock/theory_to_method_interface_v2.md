# Locked theory-to-method interface

The next method must escape the sigma-field generated by source stable budget. Adding features that do not refine source alias cells cannot defeat Main Result I's envelope. Enforcing a source-monotone mapping additionally pays the exact barriers in Main Result II.

The preferred interface is one prefix-preserving target search exposing a small frozen state at a few checkpoints. The method must jointly specify state extraction, stop/continue rule, fixed fallback, candidate-selection procedure, and all costs. It must demonstrate native/prefix equivalence, count checkpoint extraction and controller overhead, and certify the complete policy on an independent split. Repeated probes are not an acceptable proxy for resumable execution because frozen traces show a separate repetition tax.

Before confirmation, compute: target-state alias reduction; perfect-label Oracle headroom; right-censoring; expected prefix versus repeated cost; exact certification power for one frozen policy or a prespecified family; fail-closed expected cost and break-even workload. If the fixed fallback itself violates the risk target—as in the GloVe calibration autopsy—the fallback or target must be repaired in a new design phase before any stopping model can certify.

This lock authorizes method derivation, not performance execution. A fresh preregistration is required; RCRS thresholds, features, data, and candidates from the frozen sprint may not be retuned.
