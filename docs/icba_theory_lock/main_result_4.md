# Main Result IV: Cost-Adjusted Value of Target-Side Sequential Information

## Information and acquisition cost

Let `F_1 subseteq ... subseteq F_T` be the filtration generated by target-native search state. If the admissible policy class at `t+1` contains the class at `t`, then the risk-constrained decision component satisfies `V_delta(F_{t+1})<=V_delta(F_t)`. This is information monotonicity only. Let `K_t` be cumulative cost to reach checkpoint `t` in one prefix-preserving execution and define `W_delta(t)=V_delta(F_t)+K_t`. Because information can reduce `V` while acquisition increases `K`, `W` need not be monotone and the best checkpoint minimizes their sum.

## Boundary constructions (`FORMALLY PROVED BY EXAMPLES`)

1. If the added state is independent of target demand, `V` is unchanged while positive `K` makes net value negative.
2. Perfect target-demand information can still have negative net value when the cost of reaching it exceeds every avoidable downstream cost.
3. With prefix resumability, a moderately informative checkpoint can have positive net value when its cumulative work is reused after continue/fallback.
4. Repeated independent probes can reverse that conclusion because the same prefixes are repaid; equal statistical information does not imply equal operational value.

## Finite-state method interface (`PROVED UNDER EXPLICIT CONDITIONS`)

For finite state/action spaces, a known Markov transition model, additive incremental search cost, and a Lagrange multiplier lambda for failure, the recursion

`J_t(s)=min{stop_cost(s)+lambda stop_risk(s), incremental_cost+E[J_{t+1}(S_{t+1})|S_t=s]}`

is standard finite-horizon dynamic programming. It solves the Lagrangian problem. It equals the original constrained optimum only under an appropriate multiplier/duality condition or randomized-policy convexification; no unrestricted Bellman optimality claim is made. Existing RCRS logistic scores are not asserted to estimate `J`.

## Frozen trace contact

The analysis uses only the existing SIFT seed-7 and GloVe seed-7/17/29 traces. A perfect-label Oracle selects the first checkpoint whose frozen label is safe and otherwise reuses the fixed fallback. Prefix-preserving cost is the cumulative NDC at that checkpoint or the fixed native NDC at fallback. Repeated-probe cost sums every separately executed checkpoint and adds a full fallback rerun when needed. Their difference is the resumability value.

Every result is labeled `NON_DEPLOYABLE_TARGET_STATE_ORACLE_VALUE`. It is an upper bound using perfect labels, not a learned stopping-policy result. Actual wall-clock controller overhead is `NOT_ESTIMABLE`; the maximum tolerable NDC overhead is at most the Oracle NDC saving. Right-censored queries are those with no safe recorded checkpoint and use the fixed fallback.
