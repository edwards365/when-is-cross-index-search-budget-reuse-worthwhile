# Counterexamples and proof boundaries

1. Flat costs invalidate uniqueness and the zero-tax⇒measurability converse: two different budgets on one flat cost segment have zero cost difference.
2. Tied source budgets with distinct target budgets create positive information/monotone tax without a strict inversion between distinct source levels.
3. Many inversions across an almost-flat cost increment yield small tax; one inversion across a large jump can dominate tax. Inversion rate is not a cost estimator.
4. Right-censored target demand can make clipped observed tax zero while true safe cost is unidentified; censored zero cannot prove portability.
5. A monotone score transform preserves AUROC/AUPRC but changes fixed numeric-threshold risk; ranking does not certify a policy.
6. A highly informative target state can have negative net value if acquisition cost exceeds avoidable work. More information does not imply lower total cost.
7. Repeated probes can turn a positive prefix-preserving information value negative by repaying earlier work.
8. T4 is not promoted by finite exhaustive success. It remains a restricted proposition for finite uncensored grids, additive linear budget-gap weights, and vertex-disjoint matching.
