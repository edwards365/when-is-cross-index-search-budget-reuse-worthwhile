## Locked mathematical definitions

- **Budget set `E`:** the finite ordered grid recorded by each frozen experiment. The Cross-Index contact grid is `{10,16,24,32,48,64,96,128,192,256,384,512}`. No interpolation is an observed action.
- **Stable sufficient budget `B_I(q;tau)`:** the least `e in E` for which `R_I(q,e') >= tau` for every observed `e' >= e`.
- **Quality target `tau`:** Recall@10 `>=0.9` for the unified ICBA contact analysis. A source experiment with another frozen target remains a separate evidence unit.
- **Cost `C_I(q,e)`:** native exact distance computations (NDC) at action `e`. NDC is implementation-local; normalized ratios may be contrasted, raw NDC may not be pooled across implementations.
- **Pointwise safety:** `g(X(q)) >= B_I(q)` almost surely, equivalently no under-budget query in the finite empirical population.
- **Marginal delta-risk:** `P[g(X(q)) < B_I(q)] <= delta`; this is not conditional or pointwise safety.
- **Conditional risk:** failure probability conditional on an explicitly named information cell; no automatic conversion from marginal control.
- **Source summary `X_s`:** a frozen function of the query and source build. Main empirical results use the frozen source stable budget directly; no post-result binning is permitted.
- **Source information:** the sigma-field generated by `X_s`.
- **Target filtration `F_t`:** increasing sigma-fields generated by target-native states observable after reaching checkpoint `t` in one search execution.
- **Right censoring:** `B_I(q)>e_max` when no stable sufficient budget occurs on the frozen grid. Observed maximum-grid cost is a clipped lower bound, not identified safe cost.
- **Empirical versus population:** finite-table maxima and risks are empirical analogues. Population statements use essential suprema, almost-sure equalities, and independent calibration assumptions.
