## Mandatory claim boundaries

1. TCP means **target-selection recalibration** in the deployable positive result. Raw source TCP reuse is unsafe on both registered datasets.
2. TCP's lifecycle statement is amortized value in implementation-native distance evaluations at `N=1e6`; wall-clock remains exploratory.
3. Vamana evidence is post-hoc semantic alignment and supporting cross-family evidence, not a harmonized primary estimand.
4. Deep1M evidence covers the first one million vectors, eight builds, 56 directed build pairs, and 1,000 fresh queries.
5. One Arxiv target build does not amortize; this heterogeneity must appear in the main-paper limitations.
6. Full raw replay needs external datasets/index setup. The anonymous artifact provides portable smoke and table regeneration without identity-bearing paths.
