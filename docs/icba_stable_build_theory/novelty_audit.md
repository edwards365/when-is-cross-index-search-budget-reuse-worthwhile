# Novelty audit

## Fast decision

`DIRECT_PRIOR_ART_FOUND_REDEFINE` was **not** triggered. No Level-A source satisfied the four-part direct-prior predicate. However, the novelty ceiling is below “new general theory” because every statistical step is classical and the strongest construction-to-search ingredient has close graph-construction precedent.

## Prior decomposition

| Component | Strongest verified prior | Consequence |
|---|---|---|
| Insertion/build sensitivity | Elliott–Clark; ANNiE; Steiner-Hardness | Do not claim first observation of rebuild sensitivity. |
| Deterministic replay | HNSW implementations and MonaVec | Canonical ordering/seed is a baseline. |
| Search-aware pruning/path quality | NSG, Vamana, Yang et al. 2024 | Critical-path language and pruning-to-path reasoning are not novel in isolation. |
| Dynamic recall stability | FreshDiskANN | Do not claim first stable graph maintenance objective. |
| Per-query budget prediction | ANNiE, QBAT, Ada-ef, DARTH+, ConANN | New method must compare against per-index retraining/recalibration. |
| Risk certification | LTT, RCPS, CRC, DKW/CP | Fixed-target certification is a classical module. |
| Reject/fallback | selective classification/risk–coverage | Reject tradeoffs are classical. |

## Potentially independent contribution

The defensible novelty is the conjunction of:

1. minimum-safe-budget response as the build-stability object, with endpoint infeasibility retained;
2. a restricted robust-trace certificate that links construction changes to a one-sided budget-shift event;
3. the explicit sequence `construction -> structure -> budget -> fixed-target risk -> deployment cost`;
4. a Stable-then-Certify algorithmic interface and break-even Gate tailored to Graph-ANNS rebuilds.

This is classified `POTENTIAL_NEW_GRAPH_ANNS_RESULT` only for the restricted trace proposition and `NEW_COMBINATION_OF_CLASSICAL_RESULTS` for the full template. It is not an open-world theorem and not yet an empirically validated algorithm.

## Gate results

- **L — pass:** no direct four-part prior found.
- **S — pass:** budget-response stability is precisely defined and kept distinct from edge overlap.
- **T — restricted pass:** T-SC5/T-SC10 connect structure to budget only under robust deterministic trace assumptions.
- **A — pass for a template:** inputs, objective, constraints, pseudocode, complexity and failure modes are specified.
- **E — qualified pass:** assumptions are testable on registered design/calibration queries, not uniformly over future builds.
- **N — qualified pass:** Graph-ANNS-specific combination remains; general theory novelty does not.

Accordingly, `STABLE_BUILD_THEORY_NOVEL_AND_DERIVABLE` is forbidden. The least overstated positive label is `STABILIZE_THEN_CERTIFY_TEMPLATE_AUTHORIZED`.
