# Figure Specification

## Figure: Theory-guided pruning of recovery routes

Use a top-down directed tree with five horizontal evidence bands:

1. observed cross-build response heterogeneity;
2. candidate/action attainability;
3. observable information or structural bridge;
4. independent certification and fallback;
5. mean, tail, and total economic value.

The root is “Cross-build safe-budget variation.” Split into four method families. Each family should show green nodes for established partial mechanisms, amber nodes for conditional/fixed-target results, and red terminal nodes for falsified deployment conditions. A black terminal node labeled “ICBA audit method” collects the scientific information from all four branches. Do not depict a failed route as reaching deployment.

Required branch labels:

- Reuse/recalibration → fixed-target certification → no stable incremental value.
- Build selection/construction → no jointly feasible candidate or valid native-budget surrogate.
- Portal rescue → complementarity confirmed → trigger and shared-cost failure.
- Certified auditor → unsafe acceptance controlled → fallback/abstention and decision-regret failure.

The figure caption must state that pruning is conditional on frozen method families and is not a universal impossibility tree.
