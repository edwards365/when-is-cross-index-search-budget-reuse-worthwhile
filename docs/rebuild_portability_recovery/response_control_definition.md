# Response-control definition

For source policy budget index \(\hat b_s(q)\) and target minimum safe index \(B_t(q)\), the discrete response residual is \(D_{s\to t}(q)=B_t(q)-\hat b_s(q)\). A method passes query Gate S only when the one-sided 95% Clopper–Pearson upper bound for \(\Pr[B_t(q)>U(q)]\) is at most \(\delta_q=0.05\) on the independent evaluation queries. Reported fields include empirical/p95 risk, CP upper risk, envelope shift, NDC saving, refusal, support and evidence label. Correlation metrics are descriptive only and do not affect the Gate.
